📜 A short history

Complex numbers

Complex numbers appeared while mathematicians investigated solutions to algebraic equations. Gerolamo Cardano discussed problems involving square roots of negative numbers in the 1500s. Rafael Bombelli developed rules for calculating with them in the 1500s. Later, Euler popularized the symbol i, and Gauss helped establish complex numbers and the complex plane in modern mathematics.

Analytic functions

The systematic study of complex functions grew in the 18th and 19th centuries. Augustin-Louis Cauchy developed foundational results in complex differentiation and integration. Bernhard Riemann deepened the geometric and theoretical understanding, while Karl Weierstrass developed a power-series approach.

Historical note: these ideas developed over time; no single person invented all of complex algebra or analytic function theory.

🧮 Complex algebra: essentials

A complex number has the form z = a + bi, where a is the real part, b is the imaginary part, and i² = −1.

Addition / subtraction

(a+bi) ± (c+di) = (a±c) + (b±d)i

Example: (2+3i)+(4−i)=6+2i

Multiplication

(a+bi)(c+di) = (ac−bd)+(ad+bc)i

Example: (1+i)(3−2i)=5+i

Conjugate and modulus

z = a+bi,   z̄ = a−bi
|z| = √(a²+b²)

For z=3+4i, |z|=5.

Division

(a+bi)/(c+di) = ((a+bi)(c−di))/(c²+d²)

Multiply numerator and denominator by the denominator's conjugate.

Polar form

z = r(cos θ + i sin θ)
r = |z|

Euler form: z = reiθ.

De Moivre's theorem

[r(cos θ+i sin θ)]ⁿ = rⁿ(cos nθ+i sin nθ)

Useful for powers and roots of complex numbers.

✨ Analytic functions: essentials

A complex function is analytic in a region if it is complex-differentiable at every point in that region. This is a stronger condition than simply having real partial derivatives.

Complex derivative

f′(z) = limh→0 [f(z+h)−f(z)]/h

The limit must have the same value regardless of the direction from which complex h approaches 0.

Cauchy–Riemann equations

If f(z)=u(x,y)+iv(x,y), then a necessary condition is:

ux = vy
uy = −vx

With suitable continuity conditions on the partial derivatives, these equations establish analyticity locally.

Example: f(z)=z²

Let z=x+iy. Then:

z² = (x²−y²) + i(2xy)
u=x²−y², v=2xy
ux=2x=vy
uy=−2y=−vx

So z² is analytic everywhere, and f′(z)=2z.

More examples

  • f(z)=zⁿ: analytic everywhere for nonnegative integer n.
  • f(z)=eᶻ, sin z, cos z: analytic everywhere.
  • f(z)=1/z: analytic for z≠0, but not at z=0.
  • Polynomials: analytic everywhere.

Harmonic functions

uxx + uyy = 0

The real and imaginary parts of an analytic function are harmonic wherever the function is analytic.

Taylor series

f(z)=Σ [f⁽ⁿ⁾(a)/n!](z−a)ⁿ

An analytic function can be represented locally by a convergent power series around each point in its domain.

What complex mappings do

A complex function sends each input point z to an output point f(z). For example, squaring changes both the distance from the origin and the angle:

z = reiθ ⟶ z² = r²ei2θ

Distance is squared and angle is doubled.

✏️ Extra solved examples

1. Calculate (3+2i)+(1−5i)

= (3+1)+(2−5)i = 4−3i

2. Find the modulus of 5−12i

|z| = √(5²+(−12)²) = √169 = 13

3. Check f(z)=z² using Cauchy–Riemann equations

Write f(z)=x²−y²+i2xy. Thus u=x²−y² and v=2xy. Then uₓ=2x=vᵧ and uᵧ=−2y=−vₓ. The equations hold everywhere, so f(z)=z² is analytic everywhere.

4. Differentiate f(z)=z³

Using the power rule, f′(z)=3z². This function is analytic everywhere.
